# Content Generation Protocols (The "Anti-Slop" Standard)

## 1. Structural Diversity (Kill the Pattern)
**Rule:** No two consecutive blogs (or even blogs in the same batch) may use the same Intro or Outro formula.
**Forbidden:** Always starting with "Imagine a world..." or "Have you ever wondered..."
**Mandatory Rotation of Hooks:**
*   **The Narrative Hook:** Start *in media res* with a specific story/date. (e.g., "1988. Cornell University. A fan whirring.")
*   **The Contrarian Hook:** Start with a lie. (e.g., "Everything you know about [X] is wrong.")
*   **The Data Hook:** Start with a shocking stat. (e.g., "99% of the universe is invisible.")
*   **The Question Hook:** Direct Socratic questioning.

## 2. Mandatory Depth Sections
Every article MUST include at least **3** of the following headers (varied per article):
*   **🧠 Mental Model:** How to think about this concept efficiently.
*   **❌ Common Misconception:** What everyone gets wrong.
*   **🤯 Why This Is Counterintuitive:** Why logic fails here.
*   **⚠️ Where This Breaks Down:** The edge cases or limitations.
*   **📉 The Pre-Mortem:** Why this might fail in the future.
*   **⏱️ One-Minute Summary:** (Already standard, keep this).

## 3. Visual-First Thinking
Since we generate text, we must describe the visuals that *should* be there.
*   Use blockquotes to describe diagrams: `> **Chart Idea:** A Venn diagram overlapping X and Y.`
*   Ensure the `imageUrl` we pick (even if placeholder) matches the specific "Mental Model" we are building.

## 4. Authority & SEO
*   **No Fluff:** If a sentence doesn't add new information, delete it.
*   **Specifics over Generics:** Don't say "Scientists say". Say "Dr. John Smith (1994) found..."
*   **Quotable Summary:** The `One-Minute Summary` must be written as "Citation Bait"—something a user would copy-paste into a tweet.

## 5. Topic Selection Guardrails
*   **No Duplicates:** Check carefully against previous batches.
*   **Niche Down:** Instead of "Psychology", go for "The Psychology of Pricing". Instead of "Space", go for "Orbital Mechanics Disasters".

## 6. Tone Check
The content should feel like it was written by a **Smart Friend**, not a **Textbook**.
*   Use short sentences for impact.
*   Use "You" and "We".
*   Be opinionated where appropriate (e.g., "This myth is dangerous.").
